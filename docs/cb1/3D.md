# AMD HDMI 3D

Kodi handles stereoscopic playback independently of CB1. The image includes AMD
HDMI stereo-output patches and additional 1080p half-SBS modes.

## Formats

| Source | Playback path |
| --- | --- |
| MVC Blu-ray ISO | Decode both views; HDMI frame packing when the display exposes a compatible mode |
| Side-by-side (SBS) | Native Kodi stereo rendering and HDMI stereo-mode selection |
| Top-and-bottom (TAB) | Native Kodi stereo rendering and HDMI stereo-mode selection |
| 1080p half-SBS | Additional progressive HDMI stereo modes at 24, 50 and 60 Hz |

MVC frame-packed 1080p24 and half-SBS 1080p60 have been reported working on
Radeon RX 7600 with a JVC projector.
[User feedback](https://forum.libreelec.tv/thread/30362-x86-64-dolby-vision-w-fel-full-3d-for-pc-intel-amd-nvidia/?postID=208017#post208017).

## Setup

Use an AMD HDMI output, a 3D-capable TV/projector and compatible glasses.
An AVR in the connection chain must also pass the selected 3D mode.

1. In **Settings > Player > Videos**, set **Playback mode of stereoscopic 3D videos** to **Ask me** or **Preferred mode**.
2. In **Settings > System > Display**, select the preferred stereoscopic mode supported by the display.
3. During playback, use Kodi's video settings to select the source stereo layout or invert the eyes when required.
4. Adjust subtitle stereoscopic depth in Kodi's native subtitle settings if needed.

Kodi can retain SBS or TAB output when a suitable frame-packed mode is unavailable.
The selected output must match the display's 3D mode.

## Processing boundary

3D playback does not use Dolby Vision transport, AI metadata reconstruction,
Adaptive HDR Mapping or CB1 video conversion. Stereo selection, subtitles and
return to 2D remain native Kodi functions. This release does not add Dolby Vision
3D or claim equivalent HDMI 3D driver support on Intel and NVIDIA.

## Known issue

Repeated `CDropControl: lost diff` timing warnings have been reported on some
MVC ISOs. Their playback impact and cause remain under investigation; the
warnings alone do not establish visible frame drops.
